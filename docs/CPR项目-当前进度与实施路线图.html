03 / FIVE MODULES

五个人怎么推进

每人独立算法改进的要求保留。先接通各自基线，再证明新增改动；接接口、写提示词和加载旧权重不能单独算算法贡献。

当前均未实现算法
依赖关系：M1／M5可较早并行 → M2需要两路基线 → M3匹配冻结的预测版本 → M4依赖互补工具、可信度和真实成本。M3可先做单路基线；模型改变后，关联校准与策略需要重新验证。
工程工作共同承担

06 / RELEASE GATES

三个关卡，避免做成无法落地的项目

以证据决定是否推进；当前不承诺精度、固定提升百分比或未经实测的工期。

关卡A · 完整视觉链路

只有分类头或预计算特征不算视频链路已通。必须核验前置提取流程与可用权重；先决定低训练负担是否成立。

关卡B · 两路互补性

一路可运行足以启动首个可用版本，但完整M2／M4方案还需第二路和互补案例。工具数量不能替代互补效果。

关卡C · 最终交付配置

真实推理验证后冻结部署。PostgreSQL和Celery迁移不阻断首个可用版本；若最终保留轻量适配器，要同步白皮书并如实标明。

每个阶段都做受影响的回归

目标解析改变，检查对话与引用；模型／采样改变，检查识别与匹配校准；图或状态改变，检查暂停恢复与终态。最终用真实执行成本和同一目标集评估，不用预计算回放假称节省了GPU计算。
