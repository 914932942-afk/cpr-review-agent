M1 / M2：保留有证据的改进

单视角 CPR 训练错误分析与 Agent 辅助复盘系统。此次只改进骨架稳定处理与 RGB—骨架融合，M3、M4、M5 保持基线。

结论：M1 的主要收益是对连续跟踪偏移更稳健；M2 在现有真实视频回归中减少一处误报。两项已通过各自门槛与完整系统验收，运行于独立版本，旧版可继续使用。

1. 两个模块分别解决什么问题

M1 · Jinlai GE

置信度与偏移一致性约束的短段修复

问题：旧算法可处理孤立跳点，但连续 3–4 帧的低置信度跟踪偏移可能扭曲关节角度和运动特征。

改进：用片段两侧原始可信锚点检查运动连续性；仅当短段所有点明显偏离，且残差近似同向、同幅时修复。再复用原有特征与冻结识别器。

边界：不提高修复点置信度，不把插值当成真实观测；长缺失、可信运动及不满足条件的变化保留原处理。它是追踪鲁棒性改进，不是新增 CPR 分类器。

M2 · Wenbo Zhang

类别专长保护与作用范围约束的冲突融合

问题：固定采用 RGB 结果可能保留弱类别误报；直接混合两路分数又可能覆盖更可靠的类别专长，或挤掉其他类别。

改进：保留既有低质量门控；高质量输入仅对未达既有可靠性门槛的 RGB 类别进行近阈值冲突仲裁。最终选择锁定 RGB 不支持类别的原结论，剩余预算只在支持范围内竞争。

边界：仅覆盖 RGB 支持的 5 类；沿用冻结类别可靠性先验。分数仍未校准，M2 不承担 M3 的概率校准职责。

视频 → 共享关键点与 RGB 特征 → M1 骨架稳健处理 → M2 受约束融合 → 证据绑定 → Agent 解释 / 复盘

算法不读取文件名中的类别，也不使用真值标签推理。Agent 的上下文、记忆、工具编排和来源约束沿用现有实现；本次未修改 Agent 决策算法。

3. 为什么这些结果可信

  • 公共数据：沿用 CPR-Coach 的原始标签和已有缓存，没有新增采集或人工标注，也未重训视觉主干或分类头。
  • 先选择、后检查：M1 从原训练集确定的 128 条记录上选择有限候选，M2 用 32 条完整配对训练记录选择参数；随后分别检查 196 条和 6 条既有验证记录。此次未打开锁定测试集。
  • 不隐藏失败：骨段约束无足够收益，直接按两路分数间隔仲裁会伤害 RGB 专长，未加偏移一致性保护的短段修复也未过门槛；这些候选均未接入运行版。
  • 消融验证：M2 去掉专长保护后同批回归 F1 为 0.8061；单独使用作用范围约束保持 0.8667。专长保护带来当前样片增益，范围约束提供“不改动无权处理类别”的工程保证。

这些验证集与 26 段视频已被此前及本次迭代检查过；此次是工程回归，不是独立盲测或跨受试者泛化结论。M1 扰动由程序生成，不能等同真实遮挡。M2 的增益仅来自一段样片，需要以后用新增独立公开样片检验稳定性；本次未据此继续调参。
