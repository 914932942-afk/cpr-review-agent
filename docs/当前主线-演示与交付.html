推荐演示顺序

1 · 先看完整复盘

打开 D01，等待视觉分析完成，再查看错误卡片和对应证据。

2 · 追问一个结论

点击 Explain 或输入问题，观察 Agent 复用已保存结果，不重复跑视觉分析。

3 · 展示范围扩展

打开 D02，先复核重点类别，再扩大范围，查看工具调用和成本感知决策。

4 · 展示跨次记忆

打开 D03，确认上一次的关注点被保留，但不会混入当前视频的预测结果。

现场体验提示

分析进行中

页面会显示当前阶段和阶段序号：读取视频 → 检查动作 → 检查视觉细节 → 整理结果。进度会保存，可以等待或取消。

出现错误时

先看页面给出的原因。预算不足可提高时间上限；来源失效可重新打开保存记录；视频无法解码时换用完整的 MP4、MOV 或 WebM。

导出与恢复

有结果后点击 Export review 导出当前报告。刷新页面或重新打开案例会恢复视频、范围和已保存结果。

文字助手状态

默认使用 Guided review 表单；只有启动 DeepSeek 模式时才会发送文字请求。视频、帧和视觉分数不会发送给语言模型。
