为什么可以省下这些计算

当前手型专家在局部图像可用时只读取 HOG 手部形状；另外三类专家读取姿态与接触区域特征。原流程仍会生成 DINO 特征，随后其中部分预测又被手型专家覆盖。

功能实际使用的特征M5 执行方式

视觉支持的5 / 7 / 9类共享人物、姿态和接触区域上下文仍对原16帧做人物与 ROI 检查
手部可用帧不足 / 存在视觉特征依赖完整原 RGB 特征启用完整视觉回退

可用性门控沿用原规则：有效手部 ROI 至少8帧。它不额外宣称能判断图像模糊程度或动作正确性。

算法设计与可证明的边界

检查原手部可用性→ 解析当前生效专家→ 合并输入特征依赖→ 按需计算 / 完整回退→ 原分类头输出

依赖不相交，输出不变：若所有生效专家都不读取未计算的特征位置，这些位置就不会影响其分数与判断。运行时会核验输入索引、模型指纹和依赖计划，模型结构改变后不能沿用旧证书。

未计算的 DINO 嵌入不会作为真实观测写进产物。轻量路径只保存实际计算的上下文与手型特征；完整回退保存完整 RGB 特征。人物绑定、ROI 有效性和样本支持判据均保留。

实现：quality-dependency-cascade-v1。贡献属于推理算法与条件计算优化，未修改识别网络权重或分类阈值。
