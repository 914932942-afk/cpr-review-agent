一、如何使用
启动：在CODE目录运行 .\scripts\start_modules.ps1
地址：http://127.0.0.1:8004

1. 上传一段完整、单机位的CPR训练短片；也可以在页面顶部恢复已有会话。
2. 按完整类别名称选择关注点，点击 Review selected categories。
3. 分析期间查看四个真实工具的阶段状态。状态来自服务端回执，不用模拟百分比。
4. 查看模型标记和保存证据。点击某项的 Review this category，只追问这一个类别。
5. Remember focus明确保存关注点；Use saved focus把它应用到当前选择，Forget明确删除。
6. Summarise record复用当前视频的兼容结果；Open printable review report打开可打印的报告。
7. 刷新页面可恢复当前请求；换浏览器也可从服务端会话列表恢复视频、历史和报告。

二、交互边界
没有视频时禁用复盘提交，不会自动创建测试素材。真实模式不展示生成素材入口。
没有已有识别结果时，解释或摘要只能说明结果缺失；不会隐式执行视觉模型。
当前关注点控制结果展示范围。现有基线仍分析完整支持类别，不宣称按需减少视觉计算。
禁用LLM时，文字请求明确打开确认表单；等待确认时可以编辑类别。表单可取消和继续。
正在执行时锁定切换视频和发起新请求。工程节点、trace和模块状态放在折叠详情中。
正确示范目录尚未接入，入口明确禁用，不返回替代或虚构示范。

三、报告
显示原始CV判定、单独评估状态、未校准分数、可核验的分支阈值、来源及限制。
分支分数与阈值不能完整解释融合决定；单独评估不覆盖原始CV结果。
导出时重新核验已有来源文件，不推理、不调用大模型、不修改历史报告对象。
来源缺失或被修改时，明确显示历史记录及错误码，不展示当前有效的阈值。
原始JSON保留在折叠详情内，方便工程排查；打印时隐藏JSON。可用浏览器打印/保存PDF。
当前导出仍是HTML页面，并非系统内置PDF生成器。

四、如何验证
自动测试：.\.venv\Scripts\python.exe -m pytest -q
契约与固定配置：.\.venv\Scripts\python.exe scripts\check_module_slots.py
前端：npm.cmd --prefix frontend run build
浏览器验收：node scripts\mainline_ui_smoke.cjs
浏览器脚本会真实分析一段已有公开视频，并检查追问、记忆、表单、取消、导出和恢复。
该脚本使用本机已安装的Edge/Playwright，完成后保留验收文件；已有验收不覆盖。
如果视频已完成但后续验收中断，可用 --resume-verified-video 继续核验，避免重复GPU计算。
验收记录：test-results/mainline-product-v1/；变更前文件和数据库备份：data/mainline-product-v1/。
