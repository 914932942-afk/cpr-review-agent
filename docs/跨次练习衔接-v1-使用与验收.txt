CPR Review · 跨次练习衔接 v1
2026-10-23

用户目的
下一次练习可以围绕上次选过的类别继续检查，也能方便地回看上次摘要。旧视频的识别结果始终属于旧视频；沿用目标不等于已分析新视频，更不自动代表进步。

使用路径
1. 在已有练习中生成 Make a recap。
2. 上传下一段视频。关注范围默认重置为 All categories，不自动继承上一页选择。
3. Continue from an earlier practice 展示最多五个较早练习的有效摘要，每个练习优先列出最新摘要。选择 Earlier recap。
4. View earlier recap 在独立弹窗中查看旧视频名、日期、范围和经重新核验的旧发现；可打开旧报告。当前视频、当前对话和分析来源不会切换。
5. Use this focus 明确沿用该摘要的类别，保存为当前练习的起始目标。可在 Focus 调整本轮范围；开始分析前可用 Start fresh 清除起始目标。
6. Start review 为新视频运行独立分析。已有新结果后，助手以新报告作为事实来源；旧摘要仍可单独查看。

启动沿用 scripts/start_product_demo.ps1，地址 http://127.0.0.1:8007。
结构化操作无需大模型；自然语言目标解析使用 -EnableDeepSeek。Key仍只保存在后端.env。
没有有效旧摘要时不展示该卡片，不制造示范记录。旧素材失效时不展示经核验的旧发现；起始范围无法重新核验时不继续作为Agent的已确认目标。用户仍可手动设置Focus并开始独立复盘。

工程边界
• 记忆类型：当前练习的“起始关注范围”，不是识别结论，也不是自动修改全局偏好。原Save focus / Forget focus不受影响。
• 持久化：沿用data/product-demo-v2/runtime/business.sqlite3，objects表中practice_focus对象；记录目标session/clip/bundle、旧报告ID与摘要哈希、类别、修订号、确认时间及完整性摘要。没有新数据库或训练数据。
• 显式操作：POST /api/sessions/{session_id}/continuity，携带source_report_id或null、revision及Idempotency-Key。重复请求复用响应；过期修订拒绝覆盖。运行中的练习及已有完整分析的练习不能改写起始目标。
• 查询：GET /api/sessions/{session_id}/continuity。候选仅来自当前所有者、同一分析版本、较早创建的其他练习的有效摘要；旧练习可晚些生成摘要，但不能借用之后创建的练习。相同视频文件会标注为同一文件的独立记录，不称为新的表现样本。
• 旧摘要预览：GET /api/sessions/{session_id}/continuity/recaps/{report_id}。重新验证旧报告、运行状态、预测回执、媒体/模型来源和摘要一致性；失效返回不可用，不触发分析。
• 上下文：新视频无自己的报告时，ContextSnapshot只从已确认且有效的practice_focus读取active_label_ids，source仍为null、source_status仍为none、recent_goals不复制旧会话。
• Agent：N01/N02可使用这个已确认目标；继承范围解析仍受原白名单和确认流程限制。请求参考时按该范围调用reference.search；请求新分析时检查新视频。旧分数、旧错误结论和旧报告正文不因沿用范围而进入新视频的事实来源。
• 新视频一旦有完整报告，当前报告的范围与证据优先于起始目标。原12节点、CV契约、模型、阈值和M1–M5实现不变。
• 不做跨次分数提升、临床能力或改善幅度的推断。这里只提供目标衔接与分开回看。
