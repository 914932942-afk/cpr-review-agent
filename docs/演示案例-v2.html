  1. 可先运行 .\.venv\Scripts\python.exe scripts/check_demo_case_readiness.py，只读检查7个案例，不创建任务或外呼。
  2. 服务位于 127.0.0.1:8007，页面显示 Connected。尚未启动时，在 CODE 下运行 .\scripts\start_product_demo.ps1。
  3. 左侧练习按最近活动排序，不依赖固定位置。按上方给出的练习名定位；C01 可在 Review history 打开完整 Video review，C06 使用 Reference comparison。
  4. 已经保存的报告、参考和起始目标可直接回看，不必启用 DeepSeek。若要现场新发文字请求，再用 -EnableDeepSeek 启动；关闭时按确认表单完成。
  5. 失败演示后切回 C01 / C02 / C03，确认可恢复。不要在系统仍分析时连续启动多个 GPU 任务。
